# Comandos del Bot

| Comando | Descripción |
|---|---|
| `/estado` | Mostrar estado del servidor (syncthing y tailscale) |
| `/pararsyncthing` | Detener el servicio syncthing |
| `/arrancarsyncthing` | Iniciar el servicio syncthing |
| `/reiniciar` | Reiniciar el servidor |
| `/arrancartailscale` | Conectar Tailscale |
| `/agregar_recordatorio HH:MM mensaje` | Agregar un recordatorio diario (ej: `/agregar_recordatorio 14:30 Reunión`) |
| `/listarrecordatorios` | Listar todos los recordatorios activos |
| `/eliminar_recordatorio <id>` | Eliminar un recordatorio por su ID |
